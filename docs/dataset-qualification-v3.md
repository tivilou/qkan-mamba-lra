# 五任务 v3 资格记录

当前状态：**insufficient；不发放正式 baseline 全量任务**。这次完成了数据泄漏修复、全量结构检查和有边界的参考诊断；完整资格仍缺 Pathfinder 的适当可学习性证据以及逐任务用途归档。机器记录为 `docs/evidence/mega-document-v3-qualification.json`。

## 任务与模型输入

研究问题是模型在固定训练预算下能否改善五个长序列分类任务。输入为原始 token／像素及允许的 padding mask，目标是分类标签；来源行号、分组哈希、原始划分、文件名、作者 ID 等元数据不进入模型。不得由标签构造输入或在测试时修复预测。

ListOps 是 10 类表达式求值；Text 是字符级二分类；Retrieval 是两篇截断文档的二分类；Image 是 CIFAR-10 灰度 10 分类；Pathfinder32 是 32×32 图像的路径关系二分类。标签语义沿固定 MEGA 字典解码，不以标签 token 的字典排序代替类别值。

冻结输入变换：ListOps 长度 2048；Text 长度 4000；Retrieval 每篇 4000、保留两个文档；token ID 保持原样并交给 embedding，pad=1、EOS=2，padding 不参与声明的有效位置 pooling。Image/Pathfinder 长度 1024，row-major，逐像素 `float32(x)/255-0.5`，不从全部划分拟合归一化。pair head、位置编码和 optimizer 等模型特有设置在 baseline 机制契约中另行固定，不能通过改变数据预处理调优测试表现。

## 数据版本与独立性

原包 SHA-256 `b141aacd5537ad6108862117597c41d9d2a67d6420c54f74c76df615073fee13`；上游源码版本见来源回执。v1 修复 Text 的 validation/test 完全重复；v2 修复 Retrieval 的重复对和冲突标签，但进一步审计发现其所有验证／测试行均至少共享一篇训练文档。因此 v2 不能用于未见文档泛化结论。

v3 在全部 v2 文档中，将精确编码身份及已验证的近重复边组成连通组；对组的稳定代表 SHA-256 以固定盐 `qkan-document-split-20261028-v1:` 分桶，按 80/10/10 赋予 train/val/test。先按输入身份分组，再读取标签统计；只保留两篇文档属于同一划分的文档对，丢弃 60,900 个跨划分对。原始 test 不再是新版本的 test，全部来源行号链保留。

## 参考诊断与评估边界

固定抽样：train≤4096、val≤1024；固定 12 epoch、batch=64 的线性 softmax 参考和 shuffled-label 对照；没有读取 test 做模型选择。Text validation 为 58.69%，Image 为 23.05%，均检测到参考信号。v3 Retrieval 为 58.20%，训练多数类预测器为 48.34%，打乱训练标签为 48.34%。ListOps 的输入解析参考在 1024 条验证样本中无错误或无效表达式。

Pathfinder 的线性参考没有检测到信号；这是弱参考的证据不足，不能据此否定任务可学习性。需适当参考的有边界验证，或核实与作者已报告可学习数据及变换的严格等价证据。Wilson 规则只作描述性筛查，不作为相关文档对的正式置信区间。以上数值均为数据诊断，不能登记为本研究正式 baseline 结果。

正式评价将使用每任务 accuracy，五任务均值采用等权宏平均，另报参数、训练／推理时间和峰值显存。超参数和最优 checkpoint 仅由 validation 选择，test 只在冻结后评估选定 checkpoint。新版本与历史 LRA/MEGA、Path-X 六任务均值不可直接比较。当前只测这些任务的效用，不据此宣称通用长程记忆或量子优势；长度外推和顺序干预属于后续单独协议。

验收回执固定代码为 `6fd939241d8d1167188d9576a25aaa9c114019a3`，调度任务 `87b98cf78b1b4fd3b2bc94b45e970251`；27 项合成测试通过，6 个产物哈希与终止回执一致。资格、来源／用途、实现保真、GPU 预检和正式结果是不同验收项。
