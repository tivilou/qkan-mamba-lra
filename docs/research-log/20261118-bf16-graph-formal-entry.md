# BF16＋Graph 从隔离诊断接入正式续跑

之前真实 GPU 隔离诊断已经通过：完整更新吞吐中位数增加5.07691%，同源数值／RNG和新进程恢复符合约定。剩下的工程问题是实际 worker 的完整状态、暂停恢复和终端看板。此次只验证这个新增路径，不重新做不变的隔离试验。

采用进程内、更新期限定的执行适配器，保持原 worker 文件与更新体字节不变；完整 micro16 走已验收 Graph，短尾显式原 BF16 eager。解析 K 梯度 hook 在 capture 外，更新结束后恢复原 forward，评估与 trace 不进入 Graph。Graph 执行谱系和当前 PID 的计数独立记录，原数值策略契约不变。

统一入口增加显式 bf16-graph profile：独立目录复制源实际最新完整状态和两个已完成结果，原科学配置不变；四个实际 worker 子进程校验 eager2、Graph2、Graph1＋新进程1及原 trace，成功回传后同一命令自动继续训练和原看板。临时6次更新全部丢弃，不推进正式源。失败会保留紧凑原生诊断并自动回传，不先读取缺失的 result 文件掩盖原因。

本地验证使用标准库、fake 状态和无数据 --help 子进程，不加载框架或操作协作者 GPU。实际 worker 原生检查将在用户执行交付命令时完成；正式持续速度和收敛结果仍待运行，不能把本地验证或既有隔离提速当成这两个结果。

撤回时先停止新 Suite；原 Suite 仍从原游标恢复。不会声称新 Graph 权重已经自动迁回旧版本。
