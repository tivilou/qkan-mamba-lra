## 项目实际工作流

本项目研究长序列分类，正式比较覆盖五种模型、五项任务，由合作者执行训练。本检查点只覆盖 Transformer 的 Retrieval 训练数值诊断。输入为两篇文档的 token ID 与填充掩码；模型分别嵌入、编码、汇聚两篇文档，配对分类头输出类别分数，训练标签通过交叉熵提供反馈。AdamW 根据梯度和既有一、二阶矩更新权重，完整 checkpoint 还保存样本位置、调度和随机状态。正式任务效果由验证、测试准确率衡量；本次没有访问这些 split，也没有新增任务效果结果。

BF16 路线仅在注意力核心中使用低精度 Q/K/V；投影、残差、前馈、分类头、损失、主权重及 Adam 保持 FP32。原候选在固定训练批次上的全局 Adam 更新差异为21.0526%，超过20%门限。上一检查点定位到四层 K 偏置贡献98.3487%的误差平方和。本轮增加独立梯度策略：在每次反向回调中把384维合并偏置的 K 段 `[128:256]` 置零，Q/V逐值保留。K参数仍可训练，原历史矩、step和权重衰减继续生效。

本轮从同一完整状态分别执行原FP32、FP32加解析梯度、BF16加解析梯度各一次完整更新。固定原step14268、128对训练样本、micro16、4000位置和dropout=0。每条路线都回滚，不提交训练进度。logits相对L2衡量输出分数偏差，交叉熵绝对差衡量损失偏差，梯度和Adam增量相对L2分别衡量反向与真实更新偏差；它们不等同于准确率、收敛或吞吐量。

## 经验、机制与证据上限

[已测事实] 在同checkpoint、同训练批次、相同原Adam历史的这次干预中，只改变K梯度定义就使原失败的全局更新门限通过，且FP32对照的影响较小。保留全部参数和原门限，使改善可以与旧结果直接核对。

[机制解释] 精确算术下，共同K偏置对同一query的可见key分数只增加常数，softmax抵消该常数。消除该理论零方向上的新梯度残余后，Adam差异显著下降，支持先前“数值残余进入小历史矩后影响更新”的解释。但有限精度前向不严格保持此不变性，本候选明确改变梯度定义；未进一步区分残余来自投影量化、SDPA反向还是归约。

[尚未证明] 单批次通过不保证多步、dropout开启、其他checkpoint或任务通过，也没有证明速度、任务收益或长期收敛。新梯度策略不能继承旧BF16的恢复认证。当前证据上限为受控单训练批次数值干预，任务收益L1/L2及完整因果机制L3均未建立。

## 唯一推荐方向

推荐：先交付本新策略的跨进程精确恢复及真实样本轨迹验证，再按原顺序扩展短轨迹和匹配完整更新时间。

- 假设：显式绑定策略版本、保留Adam及随机/样本状态后，中断恢复可精确复现连续执行。
- 最小实验：连续两次更新对比一次更新后保存、全新进程加载再更新；使用实际策略和原训练dropout/RNG，逐值核对模型、矩、step、样本位置和随机状态，同时保存固定样本 `sample-trace.v2` 并验证语义及重放。
- 成功门：连续/恢复完整状态与样本身份精确一致，策略身份完整绑定，真实trace结构、语义、重放及回滚通过；随后仍需原短轨迹和性能门。
- 终止门：策略身份缺失、历史矩或随机/样本状态偏离、trace重放失败，即停在诊断阶段；保留原门限。
- 资源估计：至少连续2次加中断/恢复合计2次完整更新及启动/trace开销，单GPU；本轮未测可用性能，900秒子进程/300秒停滞时限仍只是既有上限。
- 不确定性：训练dropout、进程重建及后续多步偏移尚无新策略实测。开发属于既有可选优化工作线；真实GPU步骤仍由合作者执行，本次只完成返回审阅。
