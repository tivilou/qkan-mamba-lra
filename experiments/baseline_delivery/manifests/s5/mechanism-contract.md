# S5 source-stage contract

Official commit 3c18fdb6b06414da35e77b94b9cd855f6a95ef17. strong-source-registry.json pins native Flax S5SSM, HiPPO/initialization helpers, SequenceLayer, StackedEncoderModel and training helpers. strong_sources verifies clean Git commit/file identities or complete offline snapshot identities, and imports actual modules. s5_encoder requires explicit eigenbasis, conjugate symmetry, direction, discretization, timescales, layer and normalization choices.

Keep complex-valued diagonal state, input/output matrices, bilinear/ZOH discretization and jax.lax.associative_scan. Preserve real-pair parameter representation and source parameter-group optimizer semantics. The official sequence model includes a Dense input encoder, normalization, residual/GLU/dropout choices; classification produces log-softmax, while the native Retrieval model uses its own four-feature MLP head. These differ from the project's common head and must not be silently mixed.

The common classification head declares float32 with JAX HIGHEST dot precision in its Flax Dense forward, independent source reference and JIT trace replay. Replay reconstructs the batch's pooling/pair features from full decoded encoder arrays, never from captured pooled/logits. The original rtol=1e-5 and atol=1e-6 checks remain required; no tolerance exception is granted. Source probe also compares compiled logits to independent head reconstruction from that forward's encoder outputs. The official encoder's operators and precision defaults are preserved.

Status: native task/training/full-state/trace adapters and explicit isolated environment recipes are implemented; current actual-device evidence is pending. All required source, recovery and trace commands are combined in scripts/run_formal_readiness.sh. A committed reviewed admission policy binds this contract and the declared adaptation diff; runtime certificates are generated only after all gates and verified return pass. Import/constructor success alone never certifies the model. Source-author score equivalence is not claimed.
